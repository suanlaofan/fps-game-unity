## Project use

The full original is retained here. Six 400 x 300 transparent crops are placed under
`Assets/Resources/Effects/CreatureBlood/` and used at runtime as randomized enemy-hit
particle textures. They are used only for the monster's bullet-hit impact; player damage
visuals are unchanged.

`ange-embed` was not available in this environment at implementation time, so this
verified CC0 source was used as the allowed fallback.
